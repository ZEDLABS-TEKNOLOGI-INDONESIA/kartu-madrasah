# kartu-madrasah

**Status**: Produk Aktif
**Kategori**: Produk Standalone — Tool CLI

## Deskripsi
Generator kartu madrasah (kartu pelajar, kartu perpustakaan, dll). Go CLI dengan utilitas CSV (csvutil/).

## Tech Stack
- Go (CLI tool)
- Input: CSV, Output: PDF/image kartu

## Catatan
- Tool CLI — tidak perlu web UI
- Sudah menggunakan Go — selaras dengan standar ZEDLABS
- Lihat attendance-card (IOT) untuk desain fisik kartu RFID
